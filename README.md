# 📊 Sales Orders Analysis Dashboard | Excel & Power BI

An end-to-end data analytics project focused on analyzing **2024 sales order data using Microsoft Excel and Power BI**. The project aims to transform raw sales data into meaningful business insights through data preparation, analysis, interactive visualizations, and dashboard reporting.

The dashboard helps explore sales performance, monitor order-related metrics, and understand business trends to support data-driven decision-making.

## 📌 Project Overview

Sales data contains valuable information about business performance, customer orders, and sales trends. However, raw data is often difficult to interpret without proper cleaning, analysis, and visualization.

In this project, I worked with a sales orders dataset for 2024 and used Excel and Power BI to organize the data, prepare it for analysis, and build a dashboard for presenting business information in a clear and accessible format.

### 🎯 Project Objectives

- Analyze sales order data for the year 2024.
- Prepare and transform raw data for meaningful analysis.
- Use Excel to organize and analyze sales records.
- Use Power Query in Power BI for data cleaning and transformation.
- Develop interactive visualizations to explore sales performance.
- Present business information through a structured dashboard.
- Demonstrate practical data analytics and business intelligence skills.

1. Open this GitHub repository.
2. Review the uploaded Excel dataset or workbook, if included.
3. Download the Power BI `.pbix` file, if available.
4. Open the file using Microsoft Power BI Desktop.

6. Refresh the data and explore the available report pages, charts, and filters.

**Requirements:**
- Microsoft Excel, if you want to explore the Excel workbook.
- Microsoft Power BI Desktop, if you want to open and interact with the Power BI report.
